# Blockfront Worlds roadmap

## Public alpha — current build

- Five playable worlds.
- FFA/TDM/Hardpoint.
- Private rooms + invite links.
- Live room browser.
- WebSocket multiplayer.
- Voxel building/mining/mobs/day-night/power circuit.
- Deployment container and Render Blueprint.
- Ads disabled but monetization surfaces prepared.

## V2.1 — polish

- Cross-world soundscape and footsteps.
- Better weapon animations and reload animations.
- Projectile model for launcher.
- World-specific spawn tuning and cover balance.
- Mobile controls or explicit desktop-only gate.
- More Voxel Frontier recipes/blocks/doors/pistons.
- Stadium synchronized football objective.
- Battle Isles temporary construction mechanic.
- Clan Kingdom destructible objectives.

## V2.2 — persistence

- Accounts/authentication.
- PostgreSQL users, XP, unlocks, stats.
- Saved cosmetics/loadouts.
- Moderation/reporting tools.
- Leaderboards.

## V3 — scalable multiplayer

- Redis-backed room/match coordination.
- Multiple game-server processes/regions.
- Server-authoritative movement and lag compensation.
- Matchmaking.
- Anti-cheat telemetry and anomaly detection.
- Observability, metrics and alerting.
- EU/US region selection.

## Revenue extensions

- Policy-compliant menu display ads.
- Natural-break H5 game ad placements after provider approval.
- Optional cosmetic store (original skins only).
- Supporter subscription/ad-free tier.
- Sponsored original worlds or tournaments, clearly labeled.
