Privacy

Public-alpha template — review before commercial launch.

Blockfront Worlds currently stores player preferences such as name, class, selected world and graphics settings locally in the browser. The game server temporarily processes room codes, gameplay state and chat messages so multiplayer can function. The public-alpha build does not include user accounts or a persistent player database.
